# StillHere project icon

Use [stillhere-icon.png](../../web/public/stillhere-icon.png) for the hackathon project image. The original final export is a **1254 × 1254 PNG**, fully opaque, with a near-black background. It is also the website icon. No text is embedded, so the symbol remains useful in compact listings.

The lime and lavender companion forms suggest a continuous S: a human guardian stays present, and their personal agent can continue authorized assistance during a break. The open space between the forms keeps the image warm and approachable without implying police or emergency-response authority.

Generated with OpenAI ImageGen and refined once to clean the edges and replace unwanted transparency. The exact [initial prompt](initial-prompt.txt) and [refinement prompt](refinement-prompt.txt) are included for reproducibility. The PNG is a raster asset, not an editable vector master. Colors include subtle generated variation around the app palette: near-black `#0c0e11`, lime `#b6f569`, and lavender `#b6a3f5`.

Use the square as supplied with its safe margins. Preserve the background when uploading. If a submission form imposes a different size or file limit, export to that requirement from this master. The existing landscape social card remains at [og.png](../../web/public/og.png).
